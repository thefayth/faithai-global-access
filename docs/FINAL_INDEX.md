## Alibaba result — not connected live

Alibaba regular Model Studio is selected in FAITHAI, **disabled and unconfigured**.
The email review established that the existing subscription is Token Plan
Individual, Singapore—not ordinary backend API credit. Alibaba's current
[documented usage scope](https://www.alibabacloud.com/help/en/model-studio/more-tools)
excludes custom application backends for Token/Coding Plans. Those keys and
endpoints are explicitly rejected. No Alibaba inference or billing change was
performed. No private email, account instance identifier, or key was published.

Core help stays free and works locally. Enabling regular Model Studio requires
separately verified API access, appropriate quota/budget, model and region, and
a consented pilot. Do not reinterpret the existing dollar caps as spending
approval or silently enable pay-as-you-go.
